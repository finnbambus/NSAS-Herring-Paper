# Analysis of Regime Shifts in North Sea Atlantic Herring (NSAS)

This project analyzes the North Sea Atlantic Herring (*Clupea Harengus*) stock for regime shifts, inspired by the methods presented in the paper ["Regime shift dynamics, tipping points and the success of fisheries management” by Blöcker et al. 2023](https://doi.org/10.1038/s41598-022-27104-y). The R code and structure are adapted from the code available on [GitHub](https://github.com/HeleneGutte/tipping_northsea_fish/tree/main).

The project explores the dynamics of the herring stock and its spawning components, looking for evidence of hysteresis patterns and abrupt shifts in relation to fishing pressure. It grew out of a bachelor thesis and is being condensed into a manuscript (see `Manuscript/`); the environmental-driver analysis of the thesis version (environmental data, plankton data and threshold GAMs) was removed.

## Folder Structure

The repository is organized into the following directories:

  * **`data raw/`**: Contains all the original, raw data as received from various sources in May/June 2025, including herring stock data (LAI, SSB) from ICES and the Pelagic Freezer Trawler Association (PFA). Environmental and plankton data from the thesis version are retained here for reference but are no longer used by the analysis.
  * **`data/`**: Contains the processed and cleaned data in `.Rdata` format, ready for analysis. These files are generated by the `data_cleanup.Rmd` script.
  * **`R/`**: Contains all the R code used for data processing, analysis, and visualization.
  * **`plots/`**: Contains the plots generated by the R scripts, including maps, time-series, and relationship plots.
  * **`Manuscript/`**: Contains the Typst manuscript of the paper.

## How to Use

1.  **Data Preparation**: Run the `R/data_cleanup.Rmd` script. This imports the raw data from the `data raw` folder, cleans it, and saves the processed data into the `data` folder as `.Rdata` files. It also generates initial exploratory plots which are saved in the `plots` folder.
2.  **Data Analysis**: Run the `R/data_analysis.Rmd` and/or `R/data_analysis_component.Rmd` script. These load the cleaned data from the `data` folder and perform the regime shift analysis for the full stock and/or each spawning component. Both utilize functions defined in `R/functions.R` and `R/model_comp_functions.R`.

## Code Description

The `R/` directory contains the following key scripts:

  * **`data_cleanup.Rmd`**: Imports and cleans all necessary raw data.
  * **`data_analysis.Rmd`**: Performs the regime shift analysis for the full stock (change-points, hysteresis, non-stationary stock-recruitment relationships).
  * **`data_analysis_component.Rmd`**: Performs the same analysis on the spawning-component level.
  * **`functions.R`**: Contains the analysis and plotting functions used in the analysis scripts.
  * **`model_comp_functions.R`**: Contains functions for fitting and comparing different stock-recruitment models and performing a leave-one-out cross-validation.
  * **`map_components.Rmd`**: Generates a bathymetric map of the North Sea showing the different herring spawning components.

## Data

### Raw Data (`data raw/`)

The analysis is based on:

  * **Herring Data**:
      * Larva Abundance Index (LAI) and Spawning Stock Biomass (SSB) data from ICES and its Herring Assessment Working Group (HAWG).
      * Official stock assessment data (Recruitment, Catch, Fishing Mortality) from the 2024 ICES advice.
  * **Geographical Data**: Shapefiles defining the herring spawning components, adapted from Payne (2010).
  * **Unused legacy data**: Environmental data (SST/SSS from Copernicus Marine) and plankton data (Continuous Plankton Recorder), kept for reference only.

### Processed Data (`data/`)

The raw data is processed into several `.Rdata` files for ease of use in the analysis:

  * **`LAI_full` & `LAI_aggregated`**: Larval Abundance Index data.
  * **`Herring_full` & `Herring_LAI`**: Herring stock data including SSB, F, and R for the full stock and split by spawning component.

## Plots

The scripts generate a number of plots, saved in the `plots/` folder, to visualize the data and analysis results:

  * **`component_map`**: A map of the North Sea showing the herring spawning component areas.
  * **`LAI_*`**: Time-series plots of the Larval Abundance Index.
  * **`SSB_cpt_*` & `cpt_grid`**: SSB time-series for each area with identified change-points.
  * **`hysteresis_*`**: Plots showing the relationship between Spawning Stock Biomass (SSB) and Fishing Mortality (F).
  * **`SRR_*`**: Stock-Recruitment-Relationship plots.
